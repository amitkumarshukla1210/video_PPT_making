# Video & Voice Studio — bug log

| # | Symptom | Root cause | Fix | Covered by |
|---|---|---|---|---|
| 1 | Music did not get quieter under the voice when previewing the ducking curve (`musicGainAt` returned full volume while a voice clip played). | The ramp factor `k` started at 1 ("normal level") and was only lowered outside the voice clip, so inside the clip the gain stayed at 100 %. | Start `k` at 0 (fully ducked) inside the clip; ramp to 1 only before/after it. | `tests/studio/timeline.test.mjs` › *music ducks under the voice and recovers* |
| 2 | Opening a project file with an unknown template id kept that id, so the page fell back silently but the file stayed invalid. | `validateProject` spread the file over the defaults *after* choosing the safe template, overwriting it. | Re-apply the validated template id after the spread. | `tests/studio/store.test.mjs` › *project JSON round trip and validation* |
| 3 | Inspiration, Film trailer, Product video and Audio documentary videos showed only a coloured background and subtitles — no on-screen text. Found by visual review of rendered frames. | The renderer drew only `scene.title`; scripts without `#` headings produce empty titles, and the template "text style" had nothing to show. | Templates now declare `onScreen`: "line" (Inspiration, Trailer — a short spoken line is the big on-screen text, and is not repeated as a subtitle) or "title" (Explainer, Product, Documentary). Product and Documentary samples got scene titles. | `tests/studio/draw.test.mjs` (3 cases); screenshots in `docs/screenshots/` |
| 4 | In the Script help text the `#` code sample broke onto its own line. | `.label` was a column flexbox, so every inline child became a row. | `.label { display: block }`. | visual check (screenshot `explainer.png`) |
| 5 | A scene length typed by the user could not go below the template minimum (e.g. 8 s for Audio documentary), so "10-second" test videos came out 16 s. | `buildTimeline` took `max(fixedSeconds, …, template minimum)`. | A user length now wins over the template minimum, but never cuts a voice clip short. | `tests/studio/timeline.test.mjs` › *a length set by the user wins…*; e2e › *every template exports a 10-second video* |
