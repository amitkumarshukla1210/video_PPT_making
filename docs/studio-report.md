# Design to Cost workspace refresh

## Result

The main app and Video & Voice Studio now share a workspace-style design while retaining the
**Design to Cost** name and existing logo. The main page has sidebar navigation, example briefs,
workspace entry points, offline capability notes, and a sample-project action that continues into
the existing local presentation and render pipeline. The Studio includes task-oriented navigation
and clear boundaries between local features and cloud-dependent capabilities.

The Studio's **Try narrated sample** action loads original bundled artwork, creates a three-scene
script, requests voice clips from the locally running voice server, and exports a real WebM with
video and Opus narration. Media editing, local storage, WebM/WAV/SRT and presentation workflows
remain available without paid cloud services or credentials.

## Offline boundaries

- Exportable narration requires the app's local voice server and a voice engine already installed.
  Browser speech voices can be previewed, but the browser does not expose their audio for export.
- MP4 fallback and MP3 require the optional ffmpeg.wasm converter. The app asks before downloading
  it; declining leaves WebM/WAV/SRT available. Native browser MP4 is used when supported.
- Hosted dubbing, speech-to-text, hosted voice generation, and sound-effects generation are not
  provided by this offline build.
- Real-time video rendering duration tracks video length; keep the browser tab open while rendering.
- The Studio sample's illustration and narration script are bundled; voice audio is generated by
  the local voice engine at run time, rather than bundled as a premade recording.

## Validation

| `python -m pytest -q tests/test_studio_e2e.py -k narrated_sample` | 1 passed; the exported sample video includes Opus audio |
| `python -m pytest -q` | 31 passed, 2 skipped |

The two skipped full-suite cases exercise MP4 conversion and MP3 encoding; both require the optional
ffmpeg.wasm core, which was not cached in this environment. The native MP4 path passed.

The browser tests use Chromium and intercept the local voice-server requests; they do not call any
hosted voice service. Video export is decoded by ffmpeg to check its media streams and duration.
